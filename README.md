# 🧮 Math Teacher AI - Comprehensive Learning Platform

A personalized AI-powered mathematics learning platform with interactive visualizations, real-time analytics, and adaptive teaching.

## ✨ Features

- **🎯 Personalized Learning**: AI adapts to each student's learning style and pace  
- **📊 Interactive Visualizations**: Rich animations for Topics 1.1, 1.2, and 1.3
- **🧠 Memory Layer**: Mem0 integration for long-term learning context
- **📈 Real-time Analytics**: Track progress, engagement, and learning patterns
- **🎮 Multiple Learning Modes**: Demo, practice, and builder tools
- **🔐 Secure Authentication**: Session management with progress tracking

## 🚀 Quick Start

- Node.js 18+
- PostgreSQL 15+
- Redis 7+
